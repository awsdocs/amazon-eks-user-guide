= AMIs and container images
:info_titleabbrev: AMI

[abstract]
--
Build compatible AMIs for Nitro Sandboxes and encrypt container images so the parent instance never accesses plaintext image contents.
--

Pods running in Nitro Sandboxes are available on EKS Auto Mode clusters without additional configuration. For self-managed or managed node groups outside of Auto Mode, build a compatible AMI using the Nitro Sandboxes binaries provided by {aws}. See the AMI build guide.

You can also encrypt the container images that run inside a sandbox so that the parent instance transfers only encrypted layer blobs and never accesses the plaintext image contents.
