= Disassociate an OIDC identity provider from your cluster
:info_titleabbrev: Unlink OIDC provider

If you disassociate an OIDC identity provider from your cluster, users included in the provider can no longer access the cluster. However, you can still access the cluster with link:IAM/latest/UserGuide/id_roles.html#iam-term-principal[IAM principals,type="documentation"].

Disassociating an OIDC identity provider is a cluster update. The cluster enters the `UPDATING` state, and the change can take several minutes to be fully applied to the cluster's API servers. You can track the progress of the update with the link:eks/latest/APIReference/API_DescribeUpdate.html[DescribeUpdate,type="documentation"] operation. If your cluster has multiple OIDC identity providers associated, you must disassociate them one at a time. Wait for each cluster update to complete before you disassociate the next provider.

. Open the link:eks/home#/clusters[Amazon EKS console,type="console"].
. In the *OIDC Identity Providers* section, select *Disassociate*, enter the identity provider name, and then select `Disassociate`.
