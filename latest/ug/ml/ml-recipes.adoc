= Recipes to optimize your Amazon EKS cluster for AI/ML workloads
:info_titleabbrev: Recipes

[abstract]
--
Follow bite-sized recipes to optimize your Amazon EKS clusters for AI/ML workloads.
--

[TIP]
====
https://events.eksworkshop.com/workshops/genai/[Register] for upcoming Amazon EKS AI/ML workshops.
====

This section is designed to provide bite-sized recipes for optimizing your Amazon EKS cluster, particularly for AI/ML workloads involving specialized hardware. Each recipe includes prerequisites, step-by-step procedures, and deployment considerations.

* <<ml-workload-placement>> — Target workloads to the right nodes using the labels that Amazon EKS applies automatically.
* <<ml-workload-topology>> — Place the Pods of a distributed job close to each other using network topology labels.
* <<ml-workload-taints>> — Keep workloads off accelerated nodes by adding taints, with EKS Auto Mode, Karpenter, and managed node groups.
* <<ml-hugepages>> — Configure hugepages for memory-intensive workloads.
* <<ml-inferentia>> — Create an inference cluster with {aws} Inferentia instances.
