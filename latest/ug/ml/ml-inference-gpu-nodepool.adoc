[#ml-inference-gpu-nodepool]
= Create a GPU NodePool for AI/ML inference
:info_titleabbrev: Inference

[abstract]
--
Create a GPU NodePool in your Amazon EKS cluster to provision GPU-enabled compute for AI/ML inference workloads.
--

[TIP]
====
https://awsworkshop.io/eks/genai?trk=4a9b4147-2490-4c63-bc9f-f8a84b122c8c&sc_channel=el[Register] for upcoming Amazon EKS AI/ML workshops.
====

This section defines an EKS Auto Mode or Karpenter NodePool in your Amazon EKS cluster that dynamically provisions Amazon EC2 G-family GPU instances, using Spot capacity with On-Demand fallback. You can optionally add reserved capacity through an Amazon EC2 On-Demand Capacity Reservation (ODCR). The GPU instances are automatically created in EKS Auto Mode or Karpenter as workloads are run on the cluster.

This section builds on the cluster you created in the <<ml-cluster-setup>> section. Complete that section first, then choose the same path (EKS Auto Mode or self-managed Karpenter) that you used to create your cluster.

- For step-by-step instructions using the {aws} CLI, see <<ml-inference-gpu-nodepool-cli>>. 
- For step-by-step instructions using Terraform, see <<ml-inference-gpu-nodepool-tf>>.

After your GPU NodePool is ready, continue to <<ml-inference-load-serve-model>> to deploy a large language model and serve inference requests.
